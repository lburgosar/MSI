# MSI NEXT UX Iteration 01 — Map-first operator preview

Status: experimental and testable; V2.1 unchanged.

This iteration turns the adaptive-grid experiment into a functional operator journey for precision spraying:

`intent → geographic area → preflight → reconnaissance → observed correction → final plan → authorization → execution`

It provides contextual primary actions, mission state, simulated resources and environment, progressive disclosure for precision fields, animated reconnaissance/execution, global progress, and visible automatic pause/explanation after wind injection.

The center is an operational map surface with simulated agricultural context, not a real basemap. Selection, erasure, adaptive resolution and GeoJSON export remain functional. Mission Runtime, real tiles, hardware and actual replanning remain intentionally disconnected.
