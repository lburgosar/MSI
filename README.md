# MSI — Mission Swarm Intelligence

MSI Simulator V2 demuestra planificación, preflight, autorización, ejecución,
telemetría, incidentes, decisiones explicables y replanificación sobre recursos
simulados heterogéneos.

## Ejecutar

Desde la raíz del repositorio:

```powershell
.\manager\mission_studio\.venv\Scripts\python.exe manager\launch_desktop.py vertical
```

El launcher abre Mission Monitor arriba y Mission Studio abajo. Las aplicaciones
siguen siendo independientes y pueden iniciarse individualmente.
